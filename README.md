Descripción del proyecto

Este proyecto integra los conocimientos adquiridos durante las semanas 5, 6 y 7 del curso Fundamentos de Python.

El programa cuenta con un menú principal que permite ejecutar dos retos: la validación de la longitud de palabras y la identificación de cuadrantes mediante coordenadas cartesianas. También incorpora una lista para almacenar las palabras ingresadas y un diccionario para identificar los cuadrantes.

Objetivo

Consolidar el uso de funciones, estructuras condicionales, ciclos, validación de datos y colecciones en un programa organizado, funcional y documentado.

Funcionalidades
1. Longitud de palabras

El programa solicita una palabra y comprueba que tenga entre 4 y 8 letras. Si el usuario ingresa un dato incorrecto, muestra un mensaje de error y permite intentarlo nuevamente.

Las palabras ingresadas se almacenan en una lista durante la ejecución del programa.

2. Cálculo de cuadrantes

El programa solicita las coordenadas X y Y, convierte los valores ingresados a números decimales mediante float() y determina el cuadrante correspondiente.

Las coordenadas iguales a cero se rechazan porque no pertenecen a ninguno de los cuatro cuadrantes.

3. Historial de palabras

Se utiliza una lista para almacenar las palabras ingresadas durante la sesión y mostrar el historial mediante un menú.

4. Diccionario de cuadrantes

Se utiliza un diccionario para relacionar los números del 1 al 4 con los nombres de los cuadrantes:

1: Cuadrante I
2: Cuadrante II
3: Cuadrante III
4: Cuadrante IV
